## 一、仓库迁移（已完成）

已将项目迁移到新仓库 `https://github.com/jerryloopback-hash/ventiPlayer.git`：

- **全新历史**：旧 git 历史里混入了 `deno.exe`（123MB）、`libmpv-2.dll`（119MB）以及多个疑似模型权重的巨型 blob（最大单文件 2.3GB，超过 GitHub 100MB 限制，直接推历史必然被拒收）。因此新仓库以当前工作区状态建了一个干净的初始提交 `v1.4.1`，跟踪文件总共约 2.6MB。
- **未提交内容已一并提交**：`enhance_panel.py` 新增的开源方案介绍卡片（+92 行）和 `logo.ico`。
- **本地旧历史保留**在本地分支 `old-main`（远端已改为 `old-origin`，即原 netizen 仓库）。确认新仓库无误后，可以删掉旧分支并执行 `git gc --prune=now` 回收本地那 2.2GB 的 pack。
- 顺手修复：`.miopen_cache/`（MIOpen GPU 内核缓存，机器相关，纯属误跟踪）已从跟踪列表移除并加入 `.gitignore`。

## 三、明显问题（建议优先处理）

### P0 — 安全相关

1. **`cookies/` 目录里存着全浏览器导出的 cookie 文件**（164KB，含 `.51sys.cumt.edu.cn` 的 refresh_token 等登录凭据）。虽然 `.gitignore` 已排除、git 历史里也确认未提交过，但这份文件包含**大量与本项目无关的网站登录态**，放在项目目录里风险很高。建议：
   - 为 B 站单独导出一份最小 cookie 文件，其余的移出项目目录；
   - 涉及的那个 refresh_token 建议主动失效重登。

### P1 — 仓库卫生

2. **`assets/` 和 `scripts/` 是空目录**，却已提交占位。要么放入内容，要么删除。
3. **`.gitattributes` 只有一行 `* text=auto`**，而 42 个 `.glsl` shader 全是第三方二进制大文件性质的文本，且你在 Windows 上会遇到 CRLF 警告（迁移时已出现）。建议为 `*.glsl`、`*.py`、`*.md` 明确声明 `text eol=lf`。
4. **README 自称有 `assets` 目录、`scripts` 目录**（仓库布局章节），与实际不符，迁移后应核对一遍。

### P2 — 结构问题

5. **`src/gui/main_window.py` 2224 行、112 个方法**，是全项目最大的维护负担。它同时负责：窗口骨架、mpv 生命周期、URL 解析入口、增强面板协调、字幕管线调度、资源监视器、快捷键、播放列表接线。建议按职责拆成 3~4 个 mixin 或子控制器（如 `PlaybackController`、`EnhanceCoordinator`、`SubtitleCoordinator`），`MainWindow` 只做组装。这是**改动收益最大**的一项。
6. **`src/core/video_export.py`（1106 行）**同样偏大，导出流水线（视频烘焙 + 音频离线重跑 + 混流）可拆成子模块。
7. **死代码残留**：`src/core/frame_gen.py` 与 `src/core/sync.py`、`player_widget.py` 里仍有 SVP/VapourSynth/RIFE 时代的痕迹（README 和 requirements.txt 已声明这些后端移除了，`src/main.py` 里那段防 VapourSynth 日志崩溃的 monkey-patch 也只服务于已移除的 SVP）。`__pycache__` 里还残留着已不存在的 `rife_infer.pyc`。建议确认功能不再依赖后整体删除。
8. **三个测试脚本没有任何框架**（裸 pytest 风格函数 + 手动运行），建议挪到 `tests/` 目录，加一个 `pytest.ini` 或至少在 README 写明运行方式。

### P3 — 文档整理

9. **根目录 5 份过程文档**（`PLAN.md`、`DEBUG_PLAN.md`、`PLAYBACK_EXPERIENCE_PLAN.md`、`video_plan.md`、`debugReport.md`）都是开发期的 plan/报告，信息量大但已部分过时（如 PLAN.md 还写着 "FastWave 实时模式"，代码里早已改为 Apollo/FlashSR 双模型）。建议：
   - 移入 `docs/dev-notes/` 归档，README 加一行链接；
   - README 中已过时的段落（早期 FastWave/SVP 描述）核对更新。
10. **无 LICENSE 声明冲突**：MIT License 已有，但 vendored 的 FlashSR/BigVGAN 带了 `incl_licenses`，建议在 README 里补一句第三方组件及其许可的说明（Apollo vendored 部分目前没看到 LICENSE 文件，需确认其上游协议是否允许再分发）。
